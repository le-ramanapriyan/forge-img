Convert images

Save images as WebP, JPEG, or PNG. The original file name stays the same — only the extension changes. Choose a preset, a percentage, or a target size.

Good to know

The right format. The same name.

Files keep their original name with the new extension. Width and height stay the same.

Lossy or lossless.

WebP and JPEG accept a preset, a percentage, or a maximum size. PNG is lossless, so those controls do not apply.
