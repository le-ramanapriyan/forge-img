# ForgeIMG

On-device image tools by **RAMANAPRIYAN M R V** ([le-ramanapriyan](https://github.com/le-ramanapriyan)).

Files never leave your browser.

## Tools

| Tool | Path |
|------|------|
| Compress images (same format) | [compress/](./compress/) |
| Convert images (WebP / JPEG / PNG) | [convert/](./convert/) |
| Resize images | [resize/](./resize/) |
| Crop images | [crop/](./crop/) |
| Lottie fallback (first frame → WebP / JPEG / PNG) | [lottie/](./lottie/) |

## Design

See [DESIGN.md](./DESIGN.md).

## Local preview

```bash
cd private-repo
python3 -m http.server 8080
```

Open http://localhost:8080/
